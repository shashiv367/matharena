## 🎮 Challenges

### 1. Graph Theory: Ambulance Routing
**Concept**: Shortest Path Algorithm (Dijkstra)

**Features**:
- Interactive graph visualization on HTML Canvas
- Click-to-build path interface
- Real-time distance calculation
- Visual feedback with colored paths
- Comparison with optimal solution
- Efficiency percentage calculation

**Scoring**:
- 100 points for optimal path
- 85 points for 90%+ efficiency
- 70 points for 80%+ efficiency
- 50 points minimum

**Learning Outcomes**:
- Understanding graph theory
- Shortest path algorithms
- Real-world optimization
- Emergency response systems

### 2. Trigonometry: Drone Path Angle
**Concept**: Angle calculation using trigonometric functions

**Features**:
- Interactive line chart showing flight path
- Real-time angle visualization
- Obstacle detection and clearance check
- Formula hints and explanations
- Dynamic path updates based on input

**Scoring**:
- 75 points for 98%+ accuracy
- 65 points for 90%+ accuracy
- 50 points for 80%+ accuracy
- 30 points minimum

**Learning Outcomes**:
- Trigonometric ratios (tan, sin, cos)
- Inverse trigonometric functions
- Real-world navigation
- Aviation/robotics applications

### 3. Integration: Energy Consumption
**Concept**: Definite integral calculation

**Features**:
- Beautiful curve visualization with shaded area
- Function: P(t) = 100 + 50sin(t)
- Step-by-step solution explanation
- Real-world energy context
- Integration bounds [0, 2π]

**Scoring**:
- 150 points for 99%+ accuracy
- 130 points for 95%+ accuracy
- 100 points for 85%+ accuracy
- 75 points for 70%+ accuracy
- 50 points minimum

**Learning Outcomes**:
- Definite integrals
- Integration of trigonometric functions
- Area under curve
- Energy consumption analysis
